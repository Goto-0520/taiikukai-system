# 千葉工業大学 体育会本部 統合管理システム

37団体・本部100名を統括する体育会本部の業務管理WebApp群。

## リポジトリ構成

```
taiikukai-system/
├── 五役/          ← マスターシート連携の本部統括システム (GAS WebApp)
│   ├── index.html
│   ├── callback.html
│   ├── 2024/
│   ├── 2025/
│   └── 2026/
├── 財務部/         ← 出納帳・予算管理 WebApp
│   ├── 2024/
│   ├── 2025/
│   └── 2026/
├── 書記部/         ← 施設予約・借用届処理 WebApp
├── 総務部/         ← 出欠管理・統計 WebApp
├── 渉外部/         ← 課外活動届・活動報告書 WebApp
├── 編集部/         ← 団体DB管理・名簿校正 WebApp
└── イベント/       ← 参加管理・フォルダ作成 WebApp
```

各部署フォルダ内の年度フォルダ（2024 / 2025 / 2026）には、
年度別のデータテンプレート・設定ファイルを格納する。

## 技術スタック

- バックエンド: Google Apps Script (GAS)
- フロントエンド: HTML / CSS / JavaScript (SPA)
- データストア: Google Sheets（ファイル名: 体育会_情報）
- ファイル管理: Google Drive
- カレンダー: Google Calendar 埋め込み
